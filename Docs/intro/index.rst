================================
Introduction and Installation
================================

Installation
--------------

Install with composer:

.. code-block:: bash

    composer require oktopost/structura

Cloning repository:

.. code-block:: bash

    git clone git@github.com:oktopost/Structura.git


Running tests
---------------

To run tests use command:

.. code-block:: bash

    composer test

To run tests with coverage, use command:

.. code-block:: bash

    composer test-cover
